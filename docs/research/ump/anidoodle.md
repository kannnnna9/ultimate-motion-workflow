[`core.ts:41–69,112`](https://github.com/alexgreensh/anidoodle/blob/4ae27d2c281fcfd01bce87ab13dc5ad4df81a795/skills/anidoodle/engine/src/canvas-core/core.ts#L41-L69) menginisialisasi state RNG sebagai uint32, memakai operasi integer JS untuk sampel, dan membangun tabel noise dari seed; `displace` menggeser koordinat x/y dengan noise itu. ## T5 — bukti penerimaan yang harus dibuat

- `ump_core/illustration.py`: `draw_svg(seed: int, palette: tuple[str, ...], subject: str) -> str`; gunakan generator lokal per panggilan, daftar bentuk berurutan, koordinat integer, urutan atribut/elemen tetap, dan serialisasi UTF-8. Palet tervalidasi harus menentukan warna dan subjek harus menentukan bentuk, bukan hanya muncul di metadata. Bentuk CSW/ASEAN dibuat sebagai skema simpul perpindahan orisinal, bukan meniru pelat jellyfish atau menyalin peta/branding.
- `tests/test_adoptions.py::test_illustration_seed`: dua proses Python terpisah dengan `PYTHONHASHSEED` berbeda menghasilkan byte UTF-8 identik untuk `draw_svg(23,("#002233","#FFAA00"),"orbit")`. Seed `24` harus mengubah geometri (bandingkan `d`/koordinat setelah XML diparse, bukan atribut metadata). Ubah palet dan cek warna bentuk; ubah subjek dan cek siluet/geometri. Tolak warna di luar format `#RRGGBB` sebelum serialisasi; output SVG lokal tidak boleh berisi script atau referensi jaringan.
- `tests/test_adoptions.py::test_episode_uses_generated_illustration` (ID usulan): render ulang dengan parameter produksi yang dicatat, cocokkan byte dengan `demo/ump-second/assets/illustration.svg` atau hasil staging bila schema mendukung generasi, dan periksa bahwa scene CSW benar-benar merujuk aset staged dengan byte yang sama. Bila schema belum punya field itu, gunakan SVG lokal yang dihasilkan dan dilacak tanpa perubahan schema dari T5; jalankan validator episode. Bukti T6: stil frame cue perpindahan menampilkan aset dan render bisa diulang tanpa cache Anidoodle. Belum dijalankan pada T1.
