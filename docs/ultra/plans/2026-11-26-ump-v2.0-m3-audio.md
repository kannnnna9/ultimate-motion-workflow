# UMP M3 — Audio Implementation Plan

**Goal:** Add optional, hash-bound audio tracks, real speech timing, one independent ASS subtitle owner, and a verified speech-to-visual anchor to the M1 custom-composition route without breaking silent or legacy jobs.
**Architecture:** Keep the existing video-only recorder as the visual master. Normalize imported audio and speech timelines in Python, run CPU ASR/alignment in a pinned offline subprocess with explicit read-only model/runtime access, then mux audio/ASS once through FFmpeg. Preserve the legacy episode pipeline and use the existing Indonesian VO as the real M3 proof input.
**Tech stack:** Python 3.11, uv, WhisperX 3.8.6 CPU backend, pinned Indonesian wav2vec2 alignment model, faster-whisper fallback, FFmpeg/FFprobe, Node/Playwright custom recorder, unittest.
**Spec:** `docs/ultra/specs/2026-11-26-ump-m3-audio-design.md` (approved 2026-11-26).

## Global Constraints

- Keep defaults at 1080×1920, 30 FPS, H.264; do not silently shorten, rescale, lower FPS, or degrade audio.
- Silent/no-speech/no-subtitle remains a valid path and must not invoke TTS, ASR, alignment, or subtitle generation unnecessarily.
- Pin the WhisperX 3.8.6 wheel SHA-256 `cb6d4fcd3fb6c42305cb8b222a33a0b78f6b657e9db3b714345fe43dc0a69c1f` (BSD-2-Clause) and CPU-only resolved dependencies with hashes; do not use `3.8.7rc1` or an unpinned branch.
- Candidate Indonesian aligner is `cahya/wav2vec2-large-xlsr-indonesian`, immutable revision `ce6da00000a403c7cf3857197f4132439667e8f0`, Apache-2.0; select its PyTorch checkpoint plus required small config/tokenizer files, verify checkpoint size 1,262,048,599 bytes and SHA-256 `c5040535ffd0d67f26d24fbebbc3b9c887450085e7014c9294e25494d7b3954b` before loading. Never download the later full two-checkpoint repository snapshot.
- Pin the offline fallback model `Systran/faster-whisper-tiny` at immutable revision `d90ca5fe260221311c53c58e660288d3deb8d356`, MIT; allow only `config.json`, `model.bin`, `tokenizer.json`, and `vocabulary.txt`, with the official `model.bin` size 75,538,270 bytes/hash and all file hashes in `scripts/asr/models.lock.json`. The selected four-file inventory is 78,203,619 bytes (the Hub `usedStorage` field covers only `model.bin`). Refresh the root-space reserve check before adding it.
- Install the ASR venv at `$HOME/.local/share/ump-v2/asr-runtime` and model cache at `$HOME/.cache/ump-v2/whisperx`, outside production, `CODE_ROOT`, and `DATA_ROOT`; keep network disabled during inference/render. Do not use the active Hermes venv or prune its shared uv cache.
- Preserve at least 5 GiB free on `/`, keep the manual UMP DATA_ROOT soft threshold at 2 GiB and hard stop at 3 GiB, and serialize model inference with rendering. If the verified resolver/model footprint, memory, or runtime does not fit, stop and report the measured blocker; do not weaken the sandbox or quality settings.
- Cap a composition at 8 audio tracks, 20 MiB per imported attachment, and 80 MiB aggregate pinned audio; track paths are generated by UMP and never accepted from tool input.
- Do not send text to Edge TTS or any other service in this milestone. Preserve/normalize native Edge boundaries from existing local data; external TTS generation requires explicit operator opt-in.
- Preserve the legacy episode path and existing `UMP VO <job_id> <rev>` attachment form. Do not modify the installed production plugin, merge, push, publish, or deploy.

## Dependency Graph

T1 → T2 → T3 → T4 → T5 → T6 (single serial lane; every task changes contracts consumed by the next).

## Review Focus

1. Stale or mismatched audio SHA reuses old speech times — reject before render and publish no artifacts.
2. A malformed attachment, symlink, unsupported codec, oversized audio, or traversal reaches FFmpeg/ASR — reject before decoding; use bounded probes and canonical revision paths.
3. Silent/no-speech jobs accidentally invoke TTS/ASR or emit an audio/subtitle stream — negative integration controls must assert zero provider calls and exact stream absence.
4. The composition draws speech text while ASS is also selected — reject a second subtitle owner and preserve the editable sidecar.
5. ASR inference can read Hermes secrets, reach the network, exceed the existing 2 GiB memory/900-second limits, or leave a child running — test each boundary; a resource failure is a recorded blocker, not permission to weaken isolation.
